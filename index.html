Información sobre CondominioX

CondominioX

Versión 5.0 — Junio 2026

Sistema web integral para la gestión de condominios residenciales. Administra propietarios, gastos comunes, recibos con pagos parciales, comunicados y reportes en Excel. Arquitectura MVC + DAO con autenticación JWT, estructuras de datos académicas y seguridad por roles.

🛡️

Seguridad

JWT stateless, control de roles, logging de accesos no autorizados

🏗️

Arquitectura MVC + DAO

Backend Flask estructurado con principios SOLID y capas separadas

📊

Reportes

Estado financiero mensual y exportación de morosidad a Excel

💳

Pagos parciales

Registro de pagos con distribución automática FIFO a gastos

📢

Comunicados

Anuncios con fecha de caducidad visibles para propietarios

🌐

Despliegue cloud

Frontend en GitHub Pages · Backend en Render · PostgreSQL
